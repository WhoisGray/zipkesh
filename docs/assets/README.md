# Artwork

`hero.svg` is the editable source for the README illustration (`hero.png`,
1600×900). `social.svg` is the editable social preview (`social.png`, 1280×640).
They are original vector artwork under the repository's MIT license.

The window is an interface illustration, not a screenshot or evidence of a
running macOS build. System controls use the real macOS appearance at runtime.
Render the SVGs to PNG with an SVG-capable browser or editor when updating them.
